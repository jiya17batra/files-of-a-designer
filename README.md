# Interactive Portfolio

An interactive portfolio website blending **design, motion, and storytelling** to create an engaging digital presence.
This project combines modern UI design, animation, and frontend engineering to showcase projects, skills, and creative work through an immersive user experience.

---

## 🌐 Live Demo

🔗 **View Portfolio:** https://jiya17batra.github.io/Interactive-Portfolio

---

## 📌 Project Overview

This portfolio was designed to go beyond a traditional static resume by creating a more interactive and memorable experience.

The goal was to build a platform that reflects both **technical capability and creative thinking**, using motion and structured storytelling to guide users through projects, skills, and personal work.

The portfolio emphasizes:

* Clean visual hierarchy
* Interactive user flow
* Smooth animations and transitions
* Responsive experience across devices

---

## ✨ Key Features

* Interactive landing experience with animated transitions
* Reusable UI components for scalable architecture
* Smooth motion-driven navigation
* Responsive design across desktop and mobile
* Structured project showcase and storytelling

---

## ⚙️ Tech Stack

* **Design & Wireframing:** Figma
* **Development:** AI-assisted workflow using Claude, HTML, CSS, JavaScript
* **Deployment:** Vercel

---

## 🛠 Engineering Highlights

* Built reusable frontend components to improve maintainability and scalability
* Implemented animation-driven interactions to enhance engagement and navigation flow
* Optimized responsiveness and cross-device compatibility for seamless browsing
* Applied modern UI/UX principles to improve accessibility and content clarity
